# 🤖 O'zbek TTS Telegram Bot

## Ishga tushirish (Windows)

### 1. Python o'rnating
https://python.org → Download → O'rnating
(O'rnatishda "Add to PATH" ni belgilang!)

### 2. Papkani oching
bot.py va requirements.txt ni bir papkaga saqlang

### 3. Kutubxonalarni o'rnating
Quyidagi buyruqni CMD da ishga tushiring:
```
pip install -r requirements.txt
```

### 4. Botni ishga tushiring
```
python bot.py
```

"✅ Bot ishlamoqda..." ko'rsangiz — bot tayyor!

---

## Botni ishlatish
- Matn yuboring → ovoz qaytaradi
- /ovoz → til tanlash (O'zbek, Rus, Ingliz, Turk)
- /help → yordam
